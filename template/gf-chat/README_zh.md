# GF Chat

一个带长期记忆的 AI 女友聊天应用。设定她的名字和性格，每天聊几句，关系会慢慢变化：
她会记住你说过的事，会写日记，也会在你很久没出现时主动找你。

## 功能

- **多种人格**：温柔、傲娇、高冷、犀利、暴躁、害羞
- **长期记忆**：后台自动抽取偏好、纠正和事件，后续对话会用到；过时记忆会被新事实推翻
- **轻量 RAG**：上传的笔记会分块索引，用 BM25 检索
- **亲密度系统**：六个等级，会改变她对你的称呼和语气
- **主动消息**：长时间未互动时，她会先开口
- **日记与时间线**：每天一篇日记，外加一份「她眼中的你」画像
- **语音**：豆包 TTS 播报与语音通话，支持自动静音断句
- **数据持久化**：记忆、日记、亲密度都保存在 `/app/data`

## 在 Sealos 上部署

1. 在模板页点击 **Deploy**
2. 填写下面的输入项
3. 打开分配到的域名，给她起个名字、选一个性格即可开始

### 输入项

| 输入 | 必填 | 说明 |
|---|---|---|
| `deepseek_api_key` | 是 | DeepSeek API Key，主对话模型 |
| `access_password` | 否 | 进入页面需要输入的密码；留空则不开启登录验证 |
| `volc_api_key` | 否 | 火山引擎语音 Key，用于语音播报与通话；不填则回退浏览器语音 |
| `bigmodel_api_key_1` | 否 | 智谱 API Key，用于记忆抽取与 Flash 备用模型 |
| `bigmodel_api_key_2` | 否 | 智谱 API Key，用于 GLM Pro 备用模型 |

## 数据持久化

模板在 `/app/data` 挂载了 1 GiB 存储卷。记忆、日记、亲密度和缓存文件在 Pod 重启、
重新部署后都会保留。

## 说明

- 容器监听 `8000` 端口，对外域名由 Ingress 自动创建
- 照片功能依赖 `dreamina-canvas` CLI，镜像内未内置，相机会自动隐藏
- 模型路由：DeepSeek 为主链路，GLM 系列作为备用
