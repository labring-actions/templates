# Skardi

## Overview

Federated SQL query server that turns YAML-defined queries into parameterized HTTP APIs across files, databases, object storage, and vector stores.

This Sealos template deploys **Skardi** as the `skardi` application. It uses the repository-maintained Sealos manifest and keeps deployment, networking, and storage configuration inside the template.

## Deploy on Sealos

Open this template in the Sealos App Store, review the configuration values, and click **Deploy**. Sealos renders the template variables, creates the required Kubernetes resources, and manages the public endpoint for the application.

## Access

After deployment, open `https://${{ defaults.app_host }}.${{ SEALOS_CLOUD_DOMAIN }}`. The concrete hostname is generated from `defaults.app_host` and your Sealos Cloud domain.

## Configuration

The following user-facing inputs are available during deployment:

| Name | Description | Required | Default |
|------|-------------|----------|---------|
| `auth_db_path` | Required when auth_mode is set. Path to the SQLite auth database file | `false` | `skardi_auth.db` |
| `auth_mode` | Authentication mode. Defaults to BETTER_AUTH_DIESEL_SQLITE — clear this field to disable auth entirely | `false` | `BETTER_AUTH_DIESEL_SQLITE` |
| `auth_secret` | Secret key used to sign sessions (32+ characters). Auto-generated by default | `false` | `<redacted>` |

Keep sensitive values in Sealos-managed inputs or generated defaults. Do not commit private credentials to the template repository.
